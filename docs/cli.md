# CLI

The package installs an `orb` command.

## Version

```bash
orb version
```

## Generate Headers

```bash
orb user-agent
```

## Spoof a Request

```bash
orb spoof-request https://example.com --no-proxy
```

## Test a Proxy Pair

```bash
orb proxy-test http://1.2.3.4:8080 https://1.2.3.4:8080
```
