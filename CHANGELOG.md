# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## [1.1.0] - 2026-03-07

### Added

- Export helpers for managed tables (`csv`, `json`, `parquet`) via `export_table`.
- Convenience retrieval method `fetch_table(limit=...)`.
- PyPI readiness improvements in packaging metadata.
- CI workflow for linting, typing, tests, and builds.
- PyPI publish workflow and docs deployment workflow.
- MkDocs documentation scaffolding.

### Changed

- Updated README with pip-first installation and release guidance.

## [1.0.2] - 2025-03-07

### Added

- Initial public release.
